# 国际化（i18n）工作流指南

本文档说明 FileCollector 的翻译体系结构与操作流程。涉及翻译、新增语言、更新翻译模板等工作时，请先阅读本文档。

> **适用场景**：新增或修改 UI 中的可翻译字符串后更新 `.po` 翻译文件；新增界面语言；修改 `po/` 目录下任何文件。

---

## 目录结构

```
po/
├── LINGUAS             # 支持的语言代码列表（每行一个）
├── POTFILES            # 包含可翻译字符串的源文件列表（供 xgettext 扫描）
├── meson.build         # i18n 构建配置（gettext preset: glib）
└── zh_CN.po            # 简体中文翻译文件
```

翻译模板 `filecollector.pot` 由 xgettext 从源码生成，**不纳入版本库**（`.gitignore` 中 `*.pot` 规则已忽略它）。需要时重新生成即可。

---

## 可翻译字符串的标记方式

源码使用 GLib gettext 机制。所有面向用户的字符串均用 `_()` 包裹，例如：

```vala
// 正确：可翻译
var label = new Gtk.Label(_("打开工作目录"));

// 错误：不可翻译
var label = new Gtk.Label("打开工作目录");
```

`.blp`（Blueprint UI 描述）文件中的字符串同样需要用 `_("...")` 标记。

`POTFILES` 列出了所有包含可翻译字符串的源文件，xgettext 只扫描该列表中的文件。如果新增了含 `_()` 字符串的源文件，**必须将其路径添加到 `POTFILES`**，否则翻译模板将漏掉该文件的字符串。

---

## 更新翻译模板与翻译

### 1. 重新生成 .pot 模板

修改了源码中的 `_()` 字符串后，需要重新生成翻译模板并合并到现有的 `.po` 文件中：

```bash
cd po
# 从 POTFILES 列出的源文件中提取可翻译字符串
xgettext --from-code=UTF-8 --language=Vala \
  --add-comments=TRANSLATORS \
  -f POTFILES \
  -o filecollector.pot

# 也可以使用 Meson 提供的快捷目标（如果已配置）
# meson compile -C build filecollector-pot
```

> `.blp` 文件需要先用 `blueprint-compiler` 编译为 `.vala` 后才能被 xgettext 扫描。如果修改了 `.blp` 中的字符串，需先构建项目再提取。

### 2. 合并模板到 .po 文件

```bash
cd po
msgmerge --update --no-fuzzy-matching --backup=none \
  zh_CN.po filecollector.pot
```

> **重要**：msgmerge 的 fuzzy 匹配不可信。它会将完全不相关的旧翻译配到新的 msgid 上。合并后**必须逐条检查**新增和变更的条目，不能盲目接受 fuzzy 标记的翻译。

### 3. 翻译

在 `zh_CN.po` 中为新增或变更的 msgid 补充翻译。可使用 poedit、Gtranslator 或直接编辑文本。

### 4. 安装翻译

```bash
# 在 build 目录下重新编译并安装
cd build
meson compile
sudo meson install
```

`meson install` 会将编译后的 `.mo` 文件部署到系统 locale 路径。仅 `meson compile` 不会更新翻译文件。

## 新增语言

1. 在 `po/LINGUAS` 中添加语言代码（如 `ja`）。
2. 复制 `zh_CN.po` 为 `<语言代码>.po`（如 `ja.po`），或从模板生成空白翻译文件：
   ```bash
   cd po
   cp filecollector.pot ja.po
   ```
3. 翻译 `.po` 文件中的条目。
4. 在 `po/meson.build` 的 `languages` 数组中添加该语言代码：
   ```meson
   i18n.gettext(gettext_package,
     preset: 'glib',
     languages: ['zh_CN', 'ja'],
     args: ['--from-code=UTF-8', '--language=Vala', '--add-comments=TRANSLATORS']
   )
   ```
5. 重新构建安装。

---

## 翻译与代码同步规则

| 触发动作 | 需要执行的翻译操作 |
| --- | --- |
| 源码中新增或修改 `_()` 字符串 | 重新生成 `.pot` → `msgmerge` 合并 → 补充翻译 → 重新构建 |
| 新增含 `_()` 的源文件 | 将路径添加到 `POTFILES` → 重新生成 `.pot` → 合并 → 翻译 |
| 新增 `.blp` 文件中的字符串 | 先编译 Blueprint → 重新生成 `.pot` → 合并 → 翻译 |
| 新增界面语言 | 在 `LINGUAS` 添加语言代码 → 创建 `.po` → 在 `meson.build` 的 `languages` 数组添加 → 翻译 |
| 临时切换运行语言 | 使用 `LANGUAGE=en filecollector` 环境变量，对 GUI 和 CLI 均生效 |

## 双语文档同步

项目维护两套手动维护的双语文档对，修改任一版本后**必须同步另一版本**：

| 中文文档 | 英文文档 |
| --- | --- |
| `README.md` | `README_EN.md` |
| `docs/USAGE.md` | `docs/USAGE_EN.md` |

同步时需确保内容结构、章节编号、代码示例、图片路径完全对应，仅语言不同。
